# ارسال کننده خودکار پیامک

اپلیکیشن اندروید برای فوروارد خودکار پیامک‌ها. هر پیامکی که طبق قوانین شما دریافت شود، به‌صورت خودکار و کامل به شماره دلخواه شما ارسال می‌شود.

## امکانات

- **قوانین نامحدود**: هر تعداد قانون با شماره مقصد جداگانه
- **سه نوع شرط برای هر قانون**:
  - «از شماره مشخص» → هر پیامکی که از آن شماره برسد فوروارد می‌شود
  - «کلمه کلیدی در متن» → هر پیامکی که متنش شامل عبارت دلخواه شما باشد فوروارد می‌شود
  - «شماره + کلمه کلیدی» → فقط وقتی هر دو شرط همزمان درست باشند
- **ارسال مستقیم خودکار**: پیامک از سیم‌کارت خود گوشی ارسال می‌شود (بدون دخالت دستی)
- **تاریخچه ارسال**: لیست همه پیامک‌های فورواردشده با زمان، فرستنده، مقصد و وضعیت (ارسال شد / تحویل شد / ناموفق)
- **کلید روشن/خاموش اصلی**: توقف یا شروع موقت همه قوانین با یک ضربه
- **کار با شماره‌های حروفی**: فرستنده‌هایی مثل `Bank` یا `50001` هم قابل تعریف هستند
- **تشخیص هوشمند شماره‌ها**: `0912...` ، `+98912...` ، `0098912...` و `912...` همگی یکی شناسایی می‌شوند
- **پیامک‌های طولانی**: به‌صورت چندبخشی ارسال و دریافت می‌شوند
- **فونت وزیرمتن** و رابط کاربری کاملاً فارسی و راست‌چین با تم تیره
- **بدون نیاز به باز بودن برنامه**: دریافت پیامک در پس‌زمینه توسط سیستم عامل انجام می‌شود

## پیش‌نیازها

1. **Android Studio** (نسخه Hedgehog یا جدیدتر) — از [developer.android.com/studio](https://developer.android.com/studio) دانلود کنید
2. JDK 17 (همراه Android Studio به‌صورت داخلی نصب است)
3. حداقل اندروید پشتیبانی‌شده: **Android 7.0 (API 24)**

## مراحل ساخت APK

1. پروژه را دانلود و از حالت فشرده خارج کنید
2. Android Studio را باز کنید → **File > Open** → پوشه `AutoSmsForwarder` را انتخاب کنید
3. صبر کنید تا Gradle Sync تمام شود (بار اول چند دقیقه طول می‌کشد و فایل‌ها را از اینترنت دانلود می‌کند)
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** بزنید
5. فایل APK ساخته‌شده در مسیر زیر قرار می‌گیرد:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
6. فایل APK را به گوشی منتقل کنید و نصب کنید (فعال‌سازی «نصب از منابع ناشناس» لازم است)

> 💡 اگر می‌خواهید نسخه Release بسازید، از منوی Build گزینه Generate Signed App Bundle/APK را انتخاب کنید.

## راهنمای استفاده

1. برنامه را باز کنید و روی دکمه **اجازه دسترسی** بزنید؛ هر دو مجوز «پیامک» را **Allow / مجاز** کنید
2. روی دکمه **+** بزنید تا قانون جدید بسازید:
   - نوع شرط را انتخاب کنید (شماره فرستنده / کلمه کلیدی / هر دو)
   - شماره فرستنده یا کلمه کلیدی را وارد کنید
   - **شماره مقصد** را وارد کنید (پیامک‌ها به این شماره فوروارد می‌شوند)
   - **ذخیره قانون** را بزنید
3. مطمئن شوید کلید «فوروارد خودکار» روشن است
4. از آیکون 🕐 در نوار بالا می‌توانید **تاریخچه ارسال** را ببینید

## نکات مهم

- ⚠️ **هزینه پیامک**: هر پیامک فورواردشده طبق تعرفه اپراتور شما محاسبه می‌شود
- 📶 وضعیت «تحویل شد» به اپراتور وابسته است؛ بعضی اپراتورها گزارش تحویل نمی‌دهند و وضعیت روی «ارسال شد» می‌ماند
- 🔋 در گوشی‌های **شیائومی / هوآوی / اوپو**: برای اطمینان از کارکرد پس‌زمینه، برنامه را در تنظیمات «شروع خودکار (Autostart)» فعال کنید و «بهینه‌سازی باتری» آن را روی «بدون محدودیت» بگذارید
- 💳 اگر پیامک شامل رمز یا کد مهم است، بدانید که متن کامل پیامک به شماره مقصد ارسال می‌شود؛ پس شماره مقصد را فقط در اختیار خودتان بگذارید
- 📱 در گوشی‌های دو سیم‌کارت، ارسال با سیم‌کارت پیش‌فرض پیامک انجام می‌شود

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| Gradle Sync خطا می‌دهد | اتصال اینترنت را بررسی کنید و از **File > Sync Project with Gradle Files** دوباره تلاش کنید |
| پیامک‌ها فوروارد نمی‌شوند | دسترسی‌های «پیامک» را در تنظیمات گوشی بررسی کنید؛ کلید اصلی روشن باشد؛ قانون فعال باشد |
| در شیائومی کار نمی‌کند | Autostart را فعال و بهینه‌سازی باتری را غیرفعال کنید |
| شماره مقصد اشتباه ارسال شد | شماره را با کد کشور یا بدون صفر امتحان کنید (مثلاً `+98912...` یا `0912...`) |

```
AutoSmsForwarder/
├── app/src/main/
│   ├── java/com/smsforwarder/auto/
│   │   ├── MainActivity.kt          ← صفحه اصلی (کلید اصلی + لیست قوانین)
│   │   ├── RuleEditorActivity.kt    ← ساخت/ویرایش قانون
│   │   ├── HistoryActivity.kt       ← تاریخچه ارسال
│   │   ├── SmsReceiver.kt           ← دریافت پیامک از سیستم
│   │   ├── Forwarder.kt             ← ارسال پیامک فوروارد
│   │   ├── SentStatusReceiver.kt    ← ثبت نتیجه ارسال/تحویل
│   │   ├── Rule.kt / RulesStore.kt  ← مدل و ذخیره‌سازی قوانین
│   │   ├── ForwardRecord.kt / HistoryStore.kt  ← مدل و ذخیره‌سازی تاریخچه
│   │   ├── Prefs.kt                 ← تنظیمات کلی
│   │   └── Utils.kt                 ← نرمال‌سازی شماره و تطبیق قوانین
│   └── res/
│       ├── font/                    ← فونت وزیرمتن
│       ├── layout/                  ← صفحه‌ها (فارسی، راست‌چین)
│       └── values/strings.xml       ← تمام متن‌های فارسی
└── build.gradle.kts                 ← پیکربندی Gradle (AGP 8.5.2 / Kotlin 1.9.24)
```
